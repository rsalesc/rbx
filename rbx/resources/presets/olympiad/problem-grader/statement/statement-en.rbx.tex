%- block legend
Given two integers $A$ and $B$, determine the value of $A + B$.

This is a function-call problem. Implement the following function:

\begin{center}
\texttt{long long sum(long long a, long long b);}
\end{center}

It receives $A$ and $B$ and must return $A + B$. Your submission must include
\texttt{aplusb.h} and must not define \texttt{main}: the grader reads the input,
calls \texttt{sum} once and prints what it returned.
%- endblock

%- block input
The grader reads a single line containing two integers $A$ and $B$ ($\VAR{vars.N.min} \leq A, B \leq \VAR{vars.N.max | sci}$).
%- endblock

%- block output
The grader prints the value returned by \texttt{sum}.
%- endblock
