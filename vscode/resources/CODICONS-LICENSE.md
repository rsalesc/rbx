# Attribution for `rbx-mismatch.woff`

`rbx-mismatch.woff` is a derivative work. Its glyph outlines are taken from the
**Visual Studio Code icon font (codicons)**, and each glyph in it is a composite
of two codicon outlines: a verdict icon and the `error` icon, placed in the
corner as a mismatch mark. See `scripts/build-mismatch-font.py`, which generates
it.
