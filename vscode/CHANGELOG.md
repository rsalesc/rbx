# Changelog

The rbx extension is released together with rbx and carries the same version
number: extension `2.0.0` is the one bundled with rbx `2.0.0`, and
`rbx vscode install` installs the extension matching your rbx.

Changes to the extension are listed in
[rbx's changelog](https://github.com/rsalesc/rbx/blob/main/CHANGELOG.md),
under the entries scoped `vscode`.

If rbx tells you the extension is outdated, run `rbx vscode install` to update
it.
